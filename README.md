# 📝 Валидация форм с Formik и Yup (ДЗ 47.1)

Проект демонстрирует создание функциональной веб-формы с использованием современных библиотек управления состоянием и валидацией.

## 🛠 Технологии
- **React**
- **Formik**: для управления состоянием формы, обработки ввода и отправки.
- **Yup**: для создания схемы валидации полей.

## 🚀 Реализованный функционал
Создана форма регистрации с четырьмя полями:
1. **Имя пользователя**: Обязательное поле, минимум 3 символа.
2. **Email**: Обязательное поле, проверка на корректность формата почты.
3. **Пароль**: Обязательное поле, минимум 6 символов.
4. **Подтверждение пароля**: Проверка на совпадение с основным паролем.

### Особенности:
- **Мгновенная валидация**: Ошибки отображаются сразу после того, как пользователь покинул поле (onBlur) или изменил значение.
- **Блокировка отправки**: Форма не отправится, пока все поля не пройдут валидацию.
- **Обработка данных**: При успешной отправке данные выводятся в консоль/alert в формате JSON.

## ⚙️ Запуск проекта
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
